# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |
| Earlier versions | No |

Kadoka Quest is an early prototype. Please update to the newest `0.1.x`
release before reporting an issue when possible.

## Reporting a vulnerability

Do not post exploit details in a public Issue. Use the repository's private
security-advisory form when it is available:

<https://github.com/tomiya7688/kadoka_quest/security/advisories/new>

If the private form is unavailable, contact the repository owner through
<https://github.com/tomiya7688> and include a short description, reproduction
steps, affected version, and any proof-of-concept only in the private message.

Reports are acknowledged after review. Fix timing depends on severity and the
maintainer's availability; please do not disclose the details until a fix or a
coordinated disclosure plan is available.
