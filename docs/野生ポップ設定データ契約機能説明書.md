# 野生ポップ設定データ契約（Issue #150）

## 範囲

マップJSONに出現率・種族の相対重み・Lv範囲・移動AI比率を記述する契約を定義する。I/Oを行わない `kadoka_engine.spawn_settings` が検証と既定値の補完を担当し、既存のDataValidatorがファイル単位の診断へ接続する。

#151の [出現テーブル編集UI](野生出現テーブル編集機能説明書.md) はこの契約を反映時・マップ保存前に利用する。#153の [ランタイム抽選](野生ポップ抽選機能説明書.md) では `pop_rate: 0` と `spawns: []` のどちらでも野生個体を生成しない。

## JSON例

```json
{
  "pop_rate": 25,
  "field_ai_weights": {"random": 70, "chase": 25, "idle": 5},
  "spawns": [
    {"species_id": "slime", "weight": 60, "min_level": 2, "max_level": 5},
    {"species_id": "ghost", "weight": 30, "min_level": 3, "max_level": 7,
     "field_ai_weights": {"random": 1}},
    {"species_id": "metal_slime", "weight": 1, "min_level": 1, "max_level": 1}
  ]
}
```

上記はマップJSONの出現設定部分のみ。種族の相対比は60:30:1であり、マップ全体の25%とは別の値。

## 既定値と検証

| 項目 | 省略時 | 有効な値 |
| --- | --- | --- |
| `pop_rate` | 100 | 0〜100の有限数値。百分率であり0〜1の確率ではない |
| `spawns` | 空配列 | オブジェクトの配列 |
| `species_id` | なし（必須） | 空でない種族ID。カタログ指定時は存在確認。ball_slimeは禁止 |
| `weight` | 1 | 0以上の有限数値。合計100の制限なし |
| `min_level` / `max_level` | 各1 | 1〜100の整数で最小≦最大 |
| `field_ai_weights` | 継承 | random/chase/idleの非負の有限数値の表 |

数値文字列・真偽値・非有限値は拒否する。空の出現表は有効。空でない出現表で全ての種族重みが0の場合はエラー（pop_rateが0でも同じ）。一部の種族重み0は有効。

AI表の省略・nullは継承。指定した表の未記述AIキーは0、合計100不要、少なくとも1つの正の重みが必要。空表・全0・未知キーはエラー。優先順位は出現項目→マップ→種族→既定70/25/5。種族側の既存ランタイムフォールバックは変更しない。

Lv既定値は各項目独立なので、min_levelだけを5にすると省略したmax_level=1と逆転しエラーになる。#153から通常域のLvは生成時に確定し、メタル域は遭遇時の動的Lvを優先する。

## APIと保存

- `validate_map_spawns(document, species_ids=None)`: `code / field / message` の診断配列。原本を変更しない。カタログ省略時は種族IDの形式のみ確認。
- `normalize_map_spawns(document, species_ids=None)`: 有効な文書を深くコピーし、省略されたpop_rate/spawns/weight/Lvだけ補完。不正ならValueError。未知のMOD項目・requires_flag・AI継承を保持。
- DataValidator: 既存のmap種族/Lv検証もこの契約へ委譲。診断にはファイルパスと対象フィールドを含める。
- GameRepository: 従来どおり同じJSONを保存・読込する。保存時の自動補完・検証の強制はこのIssueでは追加しない。

旧マップはpop_rateなしでも検証可能。原本の一括書換えやschema_version更新は不要。小数の種族重みもランタイムで整数化せず相対重みとして扱う。

## 検証

`tests/test_spawn_settings.py` で上下限・不正構造・有限数・AI継承・旧形式・非破壊補完・JSON往復保存・ファイル診断を検証する。既存のDataValidator、マップLv設定、AI割当テストも実行する。画面操作やpop_rateのゲーム内効果の確認を代替するものではない。
