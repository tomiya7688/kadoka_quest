# 野生出現テーブル編集（Issue #151）

## 操作

マップエディタで編集するマップを選び、「出現テーブル」を開く。

1. 左の候補一覧から1行を選ぶ。
2. 右の種族一覧で変更先を選び、相対重み・最小Lv・最大Lvを入力する。
3. 「編集を反映」で現在のマップへ反映する。
4. 「マップ保存」またはCtrl+SでJSONへ保存する。未反映の入力がある場合は検証・反映してから保存する。

「新規候補」で追加用の入力に切り替え、「候補を追加」で1行追加する。「選択を削除」は選択行だけを削除する。同じ種族を別条件で複数行登録していても、他の行は削除しない。

候補一覧・種族一覧には別々の縦スクロールバーがある。各一覧上のホイールでも移動できる。未反映入力がある間は行切替・新規候補・閉じるを止める。「入力を戻す」で未反映の入力だけ戻せる。反映済みの編集は閉じても維持する。

## 表示と検証

- 一覧は種族・重み・Lv範囲・相対比率を表示する。60/30/1は約65.93%/32.97%/1.10%。
- 比率は全候補の重みから算出する参考値。requires_flag等の出現条件やマップ全体のポップ率は含まない。巨大な有限重みでも合計のオーバーフローを避ける。
- 重みは非負の有限数値（小数可）、Lvは1〜100の整数で最小≦最大。ball_slimeは初期獲得専用なので登録できない。
- 全重み0の出現表は保存不可。空の出現表は保存可能で、野生出現なしになる。
- 不正な入力はメモリの候補や保存ファイルを書き換えない。ファイル保存前にも #150 の出現設定契約で検証する。
- 既存行のrequires_flag、field_ai_weights、MOD独自項目を保持する。旧形式の省略値はweight=1、min/max_level=各1。新規候補の入力初期値は重み10・Lv1〜5。
- 原本の一括移行や同梱マップのバランス変更は行わない。

## 責務と検証

`ui/spawn_table_dialog.py` は入力と表示、`apps/map_editor.py` は選択状態と編集/保存の接続、`kadoka_engine/spawn_table.py` は非破壊の候補検証と比率計算を担当する。ゲーム実行時へUIを持ち込まない。

`tests/test_spawn_table_editor.py` でマウス・キーイベント、追加/変更/削除、重複種族、未知項目保持、スクロール、未反映入力保護、不正入力、保存→再読込を一時コピーで検証する。ヘッドレス描画画像で配置も確認する。実ウィンドウの手操作は別確認。

ポップ率・AI比率は #152 の [マップ全体 / AIタブ](マップポップ率AI編集機能説明書.md) で編集する。#153で [ランタイム抽選](野生ポップ抽選機能説明書.md) に接続済み。メタル域の遭遇時Lv計算は変更しない。
