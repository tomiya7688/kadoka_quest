# 出血状態機能説明書

## 状態キー

出血の正式キーは `bleeding` とする。

species側は #14 の状態異常耐性契約に従い、`status_resistances` へ耐性を持つ。

```json
{
  "status_resistances": {
    "bleeding": "immune"
  }
}
```

未指定は `normal`。付与率補正は `very_weak / weak / normal / resist / strong / immune` を使用し、`absorb / reflect` は状態異常には使用しない。

## 戦闘中の効果

出血中は次を適用する。

- すばやさ: 0.9倍
- ぼうぎょ: 0.9倍
- ターン終了時ダメージ: 最大HPの2%（整数切り捨て、最低1）
- 同一個体へ複数の `bleeding` を重複保持しない
- `removable: true` の通常状態異常として既存の状態異常治療で解除できる
- 解除した時点で速度・防御補正も消える

効果は戦闘中の `Combatant.status_effects` にだけ保持し、個体JSONへ永続化しない。

## スキル側の追加効果契約

攻撃スキルは任意で `status_effect` を1つ持てる。

```json
{
  "id": "example_claw",
  "kind": "physical",
  "power": 0.8,
  "status_effect": {
    "id": "bleeding",
    "display_name": "出血",
    "chance": 0.2,
    "removable": true
  }
}
```

攻撃が実際にダメージを与え、対象が生存している場合だけ付与判定を行う。最終付与率は `chance × status_resistance補正` とし100%を上限とする。

## 出血無効種族

血液を持たないことが明確な種族はspeciesデータで個別に `immune` を指定する。初期設定では以下を無効とする。

- `ghost`
- `maru`
- `kadoka`
- `metal_slime`

種族familyだけを見て自動的に無効化はしない。将来の例外を許容するため、正式な判定元は各species JSONの `status_resistances` とする。
