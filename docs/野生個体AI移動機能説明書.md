# 野生個体AI移動（Issue #147）

## 挙動

`HiddenEnemyController` が #146 で抽選した個体の `ai` を読み、移動を切り替える。pygame・データ読込・描画・戦闘AIには依存しない。

- `random`: 上下左右とその場待機の候補を毎回ランダムな順に試す。プレイヤーを視認しても追跡せず、通常周期で動く。
- `idle`: その場に留まり、向きも維持する。移動抽選の乱数は消費しない。
- `chase`: 同じ行または列にいて、マンハッタン距離が `vision_range` 以下、間に `enemy_walkable` でないタイルがなければプレイヤーへ1マス近づく。見失うと通常周期のランダム移動へ戻る。

初期値は視認距離8、追跡周期320ms、通常周期950ms。追跡先が占有されていれば待機する。期限前は動かず、期限に達した更新ごとに最大1マスだけ進む。主人公の移動回数には連動しない。出現直後の初回移動は従来どおり通常周期後。

`sees_player` は移動判断時の視認結果、`chasing_player` は実際の追跡モードを表す実行時状態。加速は後者で判断し、random/idleには適用しない。どちらも描画や戦闘開始の新しい条件にはしない。

## 占有と互換性

全AIで地形の通行可否、範囲外、プレイヤー、固定モブ、他の野生個体の現在位置への進入を禁止する。個体は順番に移動するため、同じ更新内で先に移動した個体の占有も参照する。既存の正面遭遇条件・固定モブの行動・仲間のAI・セーブ形式は変更しない。

旧呼出元が `ai` を省略した実行時個体は従来の追跡/徘徊として扱う。明示的な未知AI値はランダム移動へ戻す。通常の出現処理は必ず3種類のいずれかを割り当てる。

複数追跡個体の経路予約・混雑回避・経路分散は #148 以降の範囲。今回は直線視認による基本移動までであり、壁を迂回する経路探索は追加しない。

- `tests/test_core.py`: ゲーム側の時間更新・既存の戦闘遷移。
- `tests/test_wild_enemy_rendering.py`: 移動後の向きと表示の回帰。
- 性能チェッカー `wild-movement-24`: 3種類のAIを含む24体の移動処理。
