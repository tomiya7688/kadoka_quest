# ゲーム画面の見た目と操作

## 背景と目的

Kadoka QuestのPlayer画面は、探索や戦闘の情報を読み取りやすくするため、黒い背景、白い文字、角のある太い枠へ統一します。開発者用のエディターや管理ツールは、Playerとは別の配色と操作画面を維持します。

本変更はUndertaleから着想を得た、余白と文字を中心とする画面設計です。Kadoka Questは独自の菱形カーソルと既存のキャラクター画像を使用します。他作品のキャラクター、画像、音声、台詞、ロゴは追加していません。

## 共通の表示

- ゲーム画面は黒（#000000）を背景、白（#F5F5F5）を主な文字と枠、灰色（#B7B7B7）を補足説明に使います。
- ゲーム画面は黄色（#FFE66D）と小さな菱形で選択先を示します。注意表示にも黄色を使用します。
- ゲーム画面の枠は角のある長方形です。パネルへ角丸やグラデーションは付けません。
- 日本語の表示には同梱のDotGothic16を使用します。システムに日本語フォントがなくても、同梱フォントの字形を利用できます。
- Python版は16pxの字形を補間せず整数倍で描きます。16〜31pxの指定は16px、32〜47pxの指定は32px相当になります。字形画像の行高は16px指定時に24pxです。
- Godot版は960×540の画面を整数倍率で拡大し、余った部分を余白にします。Godot版は起動時にウィンドウの最小寸法を表す `Window.min_size` へ960×540を設定します。headlessの画面用probeは、このプロパティ値を確認します。OS上で実際にウィンドウを縮小した際の挙動は未確認です。
- 長い名前や説明は、各画面の領域内で折り返すか切り抜きます。表示の切り抜きによって個体名や保存データ自体を短縮することはありません。

Python版の画面全体を可変サイズで整数拡大する機能は、本変更では追加していません。Python版の文字の整数拡大と、Godot版の画面全体の整数拡大は異なる機能です。

Python版の模擬戦受付（simulation_manager）は、今回の白黒テーマへの切替対象に含みません。模擬戦受付は既存の配色を維持します。タイトル、フィールド、会話、実際の戦闘、牧場が今回の切替対象です。

## Python版の起動と操作

リポジトリ直下で、pygame-ceを導入したPython環境から python launcher.py を実行してください。起動したタイトル画面でセーブを選ぶと、選択したセーブのゲームを開始できます。セーブの新規作成や別名保存の操作は、画面に表示された名前を確認してから実行してください。

| 画面 | 操作 | 画面の動作 |
| --- | --- | --- |
| タイトル | 方向キー、Tab、Enter、マウスを使用してください。 | タイトルの項目とセーブ操作の選択先を移動し、決定した操作を実行します。 |
| セーブ一覧 | ↑↓、PageUp/PageDown、Home/Endを使用してください。 | セーブの選択行と表示位置が一緒に移動します。 |
| フィールド | 方向キーまたはWASDで移動し、Spaceで正面を調べてください。 | 主人公が移動し、正面の対象に対応する会話や操作を実行します。 |
| フィールドのメニュー | Escまたは画面のメニューボタンを使用してください。 | 仲間管理、行動指針、個体取込、編成の保存・読込、操作説明などを表示します。メニュー表示中は移動入力を止めます。 |
| フィールドの会話 | 続きがある場合はEnterまたはSpaceを押してください。 | 長い会話を3行ずつ送ります。移動すると会話表示を閉じます。 |
| フィールドの個体選択 | 1〜4キーまたはメニュー内の個体を選んでください。 | 行動指針やAI初期化の対象個体を変更します。 |
| 戦闘 | 方向キーでコマンドを選び、Enterで決定してください。1〜4キーでも直接実行できます。 | 上段に敵、中央に味方のHP・MP、下段に行動表示とコマンドを表示します。 |
| 戦闘のオート | Aキーを押してください。 | 既存のオート戦闘設定を切り替えます。 |
| 戦闘終了 | 結果が表示されたらEnterを押してください。 | フィールドへ戻ります。 |
| 牧場の操作先 | TabまたはShift+Tabを押してください。 | 所有一覧、保存パーティ一覧、タブ、操作ボタンの間で選択先を移動します。 |
| 牧場の一覧 | ↑↓、PageUp/PageDown、Home/End、ホイール、スクロールバーを使用してください。 | 所有個体またはプリセットの選択・表示位置を変更します。所有数やプリセット数を表示件数で制限しません。 |
| 牧場のボタン | ボタンを選んでEnterまたはSpaceを押すか、クリックしてください。 | パーティ追加・解除、行動指針変更、AI初期化、編成の新規保存・上書き・読込を実行します。 |
| 牧場の再読込・終了 | F5で再読込し、Escで牧場を閉じてください。 | 個体と学習傾向を再取得し、牧場を開いたゲームへ戻ります。 |

Python版の既存ショートカットも維持します。F5は取得対象の個体の取込、F7は編成の保存、F8は編成の読込です。Python版のF5は、Godot版の現在地保存とは用途が異なります。

Python版のPlayer画面は、接続済みのゲームパッドを起動時に初期化して保持します。デジタル方向パッドは方向キー、ボタン番号0は決定、番号1は取消、番号4はTab相当として扱います。機器によってボタンの表示名と番号が異なります。アナログスティックの割当変更やゲームパッドの設定画面は追加していません。ゲームパッドの実機操作は未確認です。

## Godot版の起動と操作

Godot 4.7.2で gdscript/project.godot を開き、プロジェクトを実行してください。Godot版の既存データ利用と保存先については、[Godot版の説明](../gdscript/README.md)を確認してください。

Godot版は、起動するとタイトル画面を表示します。タイトル画面には「KADOKA QUEST」の見出しと、「つづきから」「はじめから」「おわる」の三つの操作を表示します。保存済みのセーブがない場合、Godot版は「つづきから」を無効にし、「はじめから」を最初に選択します。

| 画面 | 操作 | 画面の動作 |
| --- | --- | --- |
| タイトル | 矢印またはTabで操作を選び、Enterで決定してください。 | 「つづきから」はセーブ一覧、「はじめから」はセーブ名の入力、「おわる」はゲームの終了へ進みます。 |
| タイトルのセーブ一覧 | ↑↓でセーブを選び、Enterまたは「この冒険をはじめる」を押してください。Escで戻ってください。 | 選んだセーブの保存位置からフィールドを始めます。セーブは名前の自然順（「冒険2」の次に「冒険10」）で並びます。 |
| タイトルのセーブ名入力 | 40文字以内のセーブ名を入力し、Enterまたは「はじめる」を押してください。Escで戻ってください。 | 新しいセーブ名で、はじまりの街からフィールドを始めます。セーブフォルダは、フィールドで最初に保存したときに作られます。 |
| フィールド | 既存の移動・調べる操作を使用してください。Escでメニューを開いてください。 | 地名とメニューの導線を表示し、メニューから仲間、保存、読込へ進めます。従来のF5・F9・F6も使えます。 |
| 会話 | 表示領域を超える本文はスクロールしてください。移動またはEscで閉じてください。 | 話者名と本文を別の領域へ表示します。 |
| 所有一覧 | ↑↓、PageUp/PageDown、Home/Endで一覧を移動してください。Eで編成を開いてください。 | 所有個体をスクロールし、パーティの編集画面へ進みます。 |
| パーティ編成 | Tabで操作先を移し、右側の個体を選んでEnterを押してください。Deleteで枠から外せます。 | 個体を編成の下書きへ割り当てます。Ctrl+Sで保存し、Escで変更を取り消します。 |
| プリセット | 編成画面でPを押してください。↑↓などで選び、Enterで読み込んでください。 | 保存済み編成を下書きへ読み込みます。名前入力欄のEnterでは新しいプリセットを保存します。Escで編成へ戻ります。 |
| 暗号入力 | 入力欄または仮想かなボタンを使用してください。Tabと方向キーでボタンを選べます。 | 選択したかなのEnterで文字を追加し、入力欄のEnterで確定します。Backspaceで消し、Escで取り消します。 |

Godot版の個体一覧、編成、プリセット、暗号の画面は、内容が表示領域を超える場合にスクロールできます。Godot版のフィールド描画領域は960×448で、64pxのマスを15列×7行表示します。

Godot版では、メニューや管理画面を閉じたときに方向キーを押している場合、そのキー操作を探索へ持ち越しません。探索を再開する利用者は、方向キーを一度すべて離してから押してください。

Godot版のタイトル画面は、次のセーブ名を拒否し、理由を画面下部に表示します。拒否された利用者は、表示された理由に合わせてセーブ名を直してください。

- 空のセーブ名、前後に空白のあるセーブ名、ドットで終わるセーブ名
- パス区切りや制御文字を含むセーブ名、Windowsの予約名
- 40文字を超えるセーブ名
- 保存先に同じ名前のフォルダがあるセーブ名。state.jsonのないフォルダや、Windowsで大文字小文字だけが違う名前も含みます。既存のセーブや個体を新しい冒険へ混ぜないため、「つづきから」で選ぶか別の名前を入力してください。

Godot版のセーブ一覧には、保存先の直下にあり、state.jsonを持つセーブフォルダだけを表示します。名前の規則に合わないフォルダやリンクされたフォルダは一覧に表示せず、画面下部に件数を表示します。環境変数KADOKA_GDSCRIPT_SAVE_NAMEでセーブ名を指定して起動した場合、Godot版は従来どおりタイトル画面を表示せず、そのセーブ名のフィールドから始めます。フィールドからタイトル画面へ戻る操作と、セーブの別名保存・削除は、まだGodot版にありません。

## Python版とGodot版の範囲

| 対象 | Python版 | Godot版 |
| --- | --- | --- |
| タイトルとセーブ選択 | Player専用のタイトル画面を使用します。 | タイトル画面で既存セーブの再開と新しいセーブ名での開始を選べます。別名保存・削除・タイトルへ戻る操作は未対応です。 |
| フィールドと会話 | メニュー、ページ送り付き会話、一時通知を表示します。 | メニュー、話者付き会話、長文スクロールを表示します。 |
| 戦闘と結果 | 既存の戦闘処理を白黒の新しい配置で表示します。 | 本変更で戦闘画面は追加していません。 |
| 所有個体と編成 | 牧場で個体情報、学習傾向、現在パーティ、プリセットを表示します。 | 既存の所有一覧、編成、プリセットを共通テーマで表示します。 |
| AI変更と初期化 | 既存の行動指針変更とAI初期化を維持します。 | 本変更で個体編集やAI編集は追加していません。 |
| 開発者向け画面 | 既存のDeveloper・エディター用UIを維持します。 | Playerのテーマ変更でエディター機能を追加することはありません。 |

## 実装と確認の境界

Python版の見た目は ui/game_ui.py の公開APIから利用します。白黒の描画部品、文字の計測とキャッシュ、入力操作はゲーム用モジュールに置き、エディターが使う ui/common.py の配色は変更しません。画面は既存のSession、Store、コマンド経路を利用し、見た目の変更を理由に戦闘計算やセーブ形式を変更しません。

Python版の集中回帰テストは、長い日本語、改行、描画範囲、画像コピー、フォント再初期化、空一覧、大量項目、キーボード選択、ゲームパッドイベント変換を確認します。牧場の操作テストでは専用の一時保存領域を使用します。Godot版の確認にはheadlessでのimportと画面用probeを使用します。Godot版のタイトル画面からの起動・新規開始・保存・再起動・セーブ選択は、[Godot版のE2E](../tests/e2e/README.md#godot版のe2e)が起動画面への実入力とGodotの再起動で確認します。

headlessの描画と合成イベントの成功は、実際のウィンドウ操作、IMEでの日本語入力、物理ゲームパッド、配布版export、リモートCIの成功を意味しません。実GUIを含む最終確認結果は、実施した環境と操作を伴う作業報告で区別してください。

フォントの出典と同梱理由は、[Python版フォントの説明](../assets/fonts/README.md)と[Godot版フォントの説明](../gdscript/assets/fonts/README.md)を参照してください。
