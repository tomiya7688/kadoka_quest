# 敵の地域別逃走（Issue #142）

## 設定と責務

- `species.json` の `flee_rates` が種族ごとの設定。メタルスライムは通常域15%、メタル域60%。設定のない他種族は従来どおり逃走しない。
- マップ直下の `encounter_context` が地域指定。省略時は `normal`。メタル域を作る際は `"encounter_context": "metal_area"` を追加する。地形や出現表はそのまま使える。
- `BattleDataLoader` が設定を戦闘参加者へ読み込み、野生戦開始時にマップの指定を `BattleEngine` へ渡す。個体データ・AI・セーブ形式には追加しない。
- `BattleEngine` は明示的なコンテキストを受けた通常戦の敵側だけを判定する。コンテキスト省略の直接呼出・`learning_enabled=False` の模擬戦・味方は対象外。

## ターン進行

すばやさ順の行動枠に到達した生存中の敵に、1ターン1回の逃走判定を行う。成功時はスキルを使わず退場し、失敗時は通常AI行動を続ける。判定前に倒された敵は逃走しない。退場後は行動・攻撃対象・スカウト・状態異常ダメージから除外する。

逃走はHPを0にする処理ではなく、戦闘内だけの `Combatant.fled` で記録する。`alive` は戦闘に参加可能かを表し、退場後はfalseになる。ログに「○○は逃げ出した！」を出し、戦闘カードを「逃走済み」に切り替える。

## 終了と報酬

- 全員逃走: 結果 `enemies_fled`。経験値なし。フィールドへ戻れるが、固定モブ撃破フラグは立てない。
- 一部撃破・残り逃走: 結果 `victory`。撃破した個体だけを経験値計算へ含める。基礎点8は通常敵を倒した場合に維持する。専用式を含む集計は [種族別撃破経験値機能説明書.md](種族別撃破経験値機能説明書.md) を参照。
- 行動ログの再生終了後に通常の確定処理を行う。仲間の既存AI保存方針は変更しない。
- 旧 `KadokaQuest.award_experience` と通常経路 `BattleProgressionService` の両方で逃走個体を除外する。

## 検証と範囲

`tests/test_enemy_flee.py` で15%/60%の境界、判定回数、非対象戦、先に倒した場合、対象除外、報酬、マップからの受渡しを確認する。専用経験値式は #143、メタル域の動的レベルは #144。実際の中盤マップ追加・接続（#141）は別作業で、本変更では地域を追加しない。
