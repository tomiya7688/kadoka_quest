# 個体AI可視化

個体・パーティ管理画面は、選択中個体のAIを読み取り専用で表示します。表示は `AiInspector` が担当し、pygameや保存I/Oには依存しません。

表示内容は、AIプロファイル、行動指針、累計戦闘回数・行動回数、学習済みスキル傾向、状況別のスキル傾向です。後者2つは影響の絶対値が大きい順に最大3件です。

AIの初期化・戦術変更は既存の操作を利用します。可視化だけで `ai.json` を変更することはありません。

Issue #183では、プレイヤー向け5指標を計算する読み取り専用APIを追加しました。詳細は [AI学習傾向サマリ](AI学習傾向サマリ機能説明書.md) を参照してください。現画面は従来表示のままです。ゲージ等の表示への組込みは #184 で行います。
