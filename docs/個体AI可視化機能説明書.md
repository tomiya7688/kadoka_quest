# 個体AI可視化

牧場と開発用の個体・パーティ管理画面の「個体情報」に、選択中個体のAI学習傾向を表示します。サマリ計算は `AiInspector`、描画は共通の `ui/ai_tendency_panel.py` が担当します。

表示内容は、攻撃性・回復優先・MP節約・瀕死時防御・格上への強気の5項目です。各項目を「とても低い / 低い / 中立 / 高い / とても高い」とゲージで表示します。ゲージ中央の線は中立です。学習記録がない項目は「未学習」、少数記録や分類不能な項目は「データ不足」として空のゲージを表示します。個体の行動指針・累計戦闘回数・行動回数も確認できます。

個体を切り替えるとその個体の最新メモリ上のAIから再計算します。別画面や戦闘で更新された保存データは、管理画面へフォーカスを戻したとき、またはF5で再読込できます。選択中の個体IDを維持して読込し、AIリセット直後も「未学習」表示へ戻ります。生のスキル/状況テーブルを表示しません。

AIの初期化・戦術変更は既存の操作を利用します。可視化だけで `ai.json` を変更することはありません。

計算式・データ不足の判定は [AI学習傾向サマリ](AI学習傾向サマリ機能説明書.md) を参照してください。ゲージは行動の選択確率ではなく、戦闘経験から覚えた傾向の相対表示です。

`tests/test_ai_tendency_ui.py` では隔離セーブと実際の両画面ループで、同種族の履歴差、F5、フォーカス復帰、個体選択、リセット、未学習/不足表示、パネル内への描画を検証します。
