# リモート変更要約ツール

`scripts/remote_change_summary.py` は、1作業の開始時にリモート変更を短く確認するための標準ライブラリだけのCLIである。

```powershell
scripts\run_python.bat scripts\remote_change_summary.py
```

既定では `origin` をfetchしてから `HEAD` と `origin/main` の共通祖先以後を比較する。出力はリモートコミット数、変更領域別の件数、最新コミット、未コミット変更と同じファイルへの重複である。ファイル本文や保存データは出力しない。

`scripts/run_python.bat` は起動前のGit実行ファイルを `KADOKA_GIT_EXECUTABLE` として引き継ぐため、pygame用に絞り込んだPython実行環境からもfetchできる。

ネットワークを使わずに確認済みの参照を読む場合は `--no-fetch` を付ける。別の比較対象は `--base` と `--remote`、表示数は `--max-commits` で指定できる。
