# 対応済みフィードバック

## 2026-09-06 MODデータ検証

対象: ChatGPT、Copilotからの「MODデータ検証を強化し、起動を止めず問題を一覧表示する」提案。

対応内容:

- pygame非依存の `DataValidator` を追加
- 未知スキル、＋分岐先、耐性名、装備カテゴリ・参照種族、マップの未知IDを一括検査
- JSON破損を例外終了させず検証結果へ変換
- ランチャー起動時に件数を表示し、専用画面で全件をスクロール表示
- ブロック・マップ・モンスターエディタの保存直後にも再検査
- 有効なID集合を `data/project.json` へ切り出し、別ゲーム向けに編集可能化
- 正常データと複数の同時エラーを自動テスト

関連資料: `docs/MODデータ一括検証機能説明書.md`
