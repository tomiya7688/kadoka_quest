# Kadoka Quest画像変換機能説明書

## 目的

Kadoka Quest本編へ取り込むモンスター画像・ブロック画像は、外部画像の解像度や色数に依存せず、64×64の低情報量ドット絵へ揃える。

エンジン自体の画像表示能力は制限しない。変換は共通ドットエディターの「Kadoka Quest本編向け取込処理」としてだけ適用する。

## 取込順序

1. 外部画像を縦横比を維持して64×64透明キャンバス内へ収める
2. 拡大補間は行わず `pygame.transform.scale` の最近傍変換を使う
3. 既存の色差指定による近似色統合を行う
4. Kadoka基本パレットへ量子化する
5. 通常の画像読込では不透明色を最大5色へ絞る
6. 編集画面の `3色 / 4色 / 5色` からさらに明示的に減色できる
7. 保存時は64×64 PNGを既存の対象パスへ上書きする

完全透明ピクセルは透明のまま保持する。アンチエイリアス由来の半透明ピクセルは低情報量化のため、最終的に透明または不透明な基本色へ整理する。

## 基本パレット

透明に加え、以下11色をKadoka Quest本編用の基本色とする。

| 色 | RGB |
|---|---|
| 黒 | `#000000` |
| 白 | `#FFFFFF` |
| 明るい灰色 | `#D6D6D6` |
| 赤 | `#E65050` |
| 青 | `#4678DC` |
| 紫 | `#9B64D2` |
| 緑 | `#5AB969` |
| 黄 | `#F0CD50` |
| 水色 | `#64D2FF` |
| ピンク | `#EB82B9` |
| 茶色 | `#915F3C` |

通常はこの中から3〜5色 + 透明を使う。

## 最大色数の選択

単純に使用頻度上位だけを残すと、目・輪郭など面積が小さい重要色が消えやすい。そのため、最初に最頻色を選び、以降は「使用頻度 × 既選択色との色差」を優先して基本色を追加する。

これにより大きな色面を残しつつ、少量でも十分に異なる色を残しやすくする。最終的な全ピクセルは選ばれた基本色のうち最も近い色へ再量子化する。

## 対象

共通 `PixelArtEditor` を使うため、同一処理が以下へ適用される。

- モンスター `portrait.png`
- モンスター `field_front.png`
- モンスター `field_right.png`
- モンスター `field_left.png`
- モンスター `field_back.png`
- ブロック appearance PNG

`まる` / `かどか` の既存画像を一括再変換する処理は持たない。編集画面で明示的に読み込み・減色した画像だけを書き換える。

## 表示時

ランタイムの `CharacterImageProvider` は従来どおり `pygame.transform.scale` による最近傍拡大を行う。保存済み64×64画像を大きく表示しても、新しい中間色や補間情報は生成しない。

高解像度・多色画像を扱うエンジン機能そのものは変更しない。
