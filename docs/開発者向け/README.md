# 開発者・実装AI向けの文書

## 目的と対象

この入口は、Kadoka Questを変更する人間の開発者と実装AIが、作業規約の正本を見つけるための案内です。ゲームの操作方法は[利用者向けREADME](../../README.md)、保存JSONの仕様は[形式仕様](../FORMATS.md)を参照してください。開発規約の本文はこのフォルダへ分離し、ゲーム仕様や操作説明へ複写しません。

## 作業前の必読規約

開発者と実装AIは、[AGENTS.md](../../AGENTS.md)で作業対象を確認してから、次の三文書を全文読んでください。規約を変更するときは対応する正本だけを編集し、入口や旧パスへ規約本文を重複記載しないでください。

| 規約の正本 | 読む目的 |
| --- | --- |
| [コーディング・説明・レビューの必須基準](コーディング規約.md) | 開発者と実装AIは、R01〜R20の読みやすさ・安全性・責務・説明・検証の禁止基準を確認してください。 |
| [責務分離と品質検査](CODING_RULES.md) | 開発者と実装AIは、UI / Process / Dataの境界と、条件に応じたUPD・性能検査を確認してください。 |
| [宣言コメント](COMMENT_RULES.md) | 開発者と実装AIは、JSON-like Comment Outsの対象・書式・内部コメント・検査方法を確認してください。 |

## 作業と検証の入口

開発者と実装AIは、[一作業のワークフロー](../ワークフロー/ワークフロー.md)に従い、リモート取得・作業範囲の選択・集中検証・必須全体検証・対象だけのコミットを行ってください。公開操作の許可はワークフローに従い、文書整理をpushやIssue変更の許可と扱わないでください。

- 開発者と実装AIは、Issueを選ぶ際に[優先度方針](../ワークフロー/Issue優先度方針.md)と[GDScript移行単位](../ワークフロー/GDScript移行実装単位.md)を確認してください。
- 実装AIは、対象コードを探す際に[CODEMAP](../CODEMAP.md)を使い、追加の調査が必要な場合だけ[コンテキスト運用](../context/WORKFLOW.md)を読んでください。
- 開発者と実装AIは、検証コマンドの用途を[開発ツール案内](../../tools/README.md)で確認してください。アーキテクチャ変更のUPD検査と実行経路変更の性能検査は、[責務分離規約](CODING_RULES.md)の条件とコマンドを使ってください。

## 共有文書と任意のローカル追加規約

このフォルダ直下の三規約と入口はGit管理する共有文書です。`ローカル専用/` はGit管理から除外し、レビュー基準・説明記述の追加規約・論文調査を置きます。公開する入口へローカル規約の本文や調査を転載しないでください。

ローカル追加規約が用意された環境では、開発者と実装AIは `ローカル専用/README.md` から必要な文書を確認してください。Codexのローカル `AGENTS.override.md` が必読を指定する追加規約は、その指示に従って読んでください。ローカル専用フォルダがないcloneでも、共有規約と検証は利用できます。ローカル専用フォルダの欠落を、必読指示がある環境の正常状態と扱わないでください。

リポジトリ直下の `コーディング規約.md` と旧 `docs/CODING_RULES.md`・`docs/COMMENT_RULES.md` は、過去のリンクを保つ移転案内です。開発者と実装AIは、新しい参照をこのフォルダの正本へ直接リンクしてください。
