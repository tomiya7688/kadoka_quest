# マップのポップ率・AI比率編集（Issue #152）

## 操作

マップエディタの「出現テーブル」を開き、「マップ全体 / AI」タブを選ぶ。

- ポップ率は0〜100%の有限数値。小数も入力可能。
- AIは「種族/既定を継承」と「マップで指定」を切り替える。
- マップで指定する場合、random（徘徊）・chase（追跡）・idle（静止）の相対重みを入力する。合計100は不要。
- マップ指定重みを正規化した比率をその場で表示する。出現候補の個別AI設定はこの比率より優先される。継承時の比率は種族ごとに異なるため、共通の数値としては表示しない。
- 「設定を反映」で編集中のマップへ反映し、「マップ保存」またはCtrl+SでJSONへ保存する。

タブを切り替えても入力は保持する。「入力を戻す」は現在のタブだけを戻す。閉じる際には非表示タブも含め未反映入力を確認する。Ctrl+Sは表示中のタブに関係なく、両タブの未反映入力を検証して保存する。

## 保存・検証

JSON形式は #150 の契約を使う。マップ直下の `pop_rate` と `field_ai_weights` を保存する。明示的に継承へ切り替えた場合は `field_ai_weights: null` とする。未編集の旧マップは省略キーをそのまま保持する（表示既定値はpop_rate=100、AI継承）。

出現候補の個別AI設定・requires_flag・その他MOD項目は変更しない。AI継承時の非表示重み欄は保存対象外。明示指定時の負数・非数値・非有限値・全0は拒否する。

両タブの入力をコピー上で準備・検証し、どちらかが不正ならマップのメモリやファイルへ部分反映しない。エラーは画面下に表示し、入力は修正できるよう残す。

## 実装範囲

`ui/map_spawn_form.py` は入力状態と表示、`ui/spawn_table_dialog.py` はタブ操作、`apps/map_editor.py` は編集/保存への接続、`kadoka_engine/spawn_controls.py` はI/Oなしの解析・検証・保存候補作成を担当する。

#153で [ランタイム抽選](野生ポップ抽選機能説明書.md) に接続済み。ポップ率は生成候補1枠ごとの確率で、0%なら野生個体を生成しない。小数の種族重みも反映する。既存のAI重み優先順位は維持する。

## 検証

`tests/test_map_spawn_controls.py` で0/100%、小数、相対比率、継承、タブ切替、未編集の旧形式、無効入力と両タブの非破壊保存、JSON再読込を一時コピーで検証する。既存の出現候補編集テストも継続する。実ウィンドウの手操作とゲーム内ポップ判定は別確認。
