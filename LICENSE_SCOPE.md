# Provisional license scope

This file defines the current license boundary while Kadoka Quest is being
reorganized. It is intentionally conservative because the player game,
developer tools, and shared Python modules are not fully separated yet.

`LICENSES/MIT.txt`:

- `tools/**`
- `developer_launcher.py`
- `block_editor.py`
- `data_creator.py`
- `map_editor.py`
- `monster_editor.py`
- `run_developer.bat`
- `build_developer.bat`
- `src/kadoka_quest/developer/**`
- `src/kadoka_quest/apps/developer_launcher.py`
- `src/kadoka_quest/apps/block_editor.py`

- `src/kadoka_quest/ui/pixel_operations.py`

Files added later are not automatically MIT-licensed merely because they are
Python files or because they are useful during development. Add them to this
list, or place a more specific license notice in their directory, when their
role is clear.

## Kadoka Quest game license

Unless a more specific license notice applies, all paths not listed in the MIT
section above are temporarily covered by
`LICENSES/KADOKA-GAME-PROVISIONAL.txt`.

This currently includes the game runtime, player-facing applications, game
data, maps, character/game assets, save/runtime support, and shared modules whose
final ownership boundary has not yet been decided.

## Generated output

The classification above controls the repository source itself. It does **not**
prevent commercial use of games generated by the Developer Tools.

Anything the Developer Tools intentionally generate, copy, or embed into a
generated project or generated build is covered by the Generated Game Exception
in the top-level `LICENSE` and may be used, modified, distributed, sublicensed,
and sold as part of the generated game.

A generated game may intentionally remain very close to Kadoka Quest in its
systems or structure. Changing only characters, only maps, or another limited
portion of content is permitted under that exception.

## Third-party material

A third-party license notice always remains applicable to the material it
covers. This scope file cannot grant rights that the Kadoka Quest project does
not own.

## Planned replacement

After the repository is physically separated, replace this provisional list
with component-local licenses, for example:

- Developer Tools / editor component: MIT License
- Generated-game runtime/template: a clearly distributable commercial-use
  license or equivalent output grant
- Kadoka Quest game/content component: Kadoka Quest game license

At that point the top-level license should become a short index to those
component licenses rather than a path-by-path transition list.
