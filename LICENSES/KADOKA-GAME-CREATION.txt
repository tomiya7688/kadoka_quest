This license allows people to use the Kadoka Quest development framework and
Kadoka Quest material to create their own games, including commercial games.

It is intentionally permissive for finished games while keeping Kadoka Quest
itself and its individual assets from becoming unrestricted standalone content.

2. Created Game

A "Created Game" is a game or game project that:

- is based on, built with, or derived from the Kadoka Quest Developer Tools,
  runtime, templates, systems, or Kadoka Quest game material; and
- contains at least one meaningful original change to the game or its content.

A Created Game does not need to be substantially different from Kadoka Quest.

For clarity, any one of the following may by itself be enough when it represents
a meaningful change:

- replacing or meaningfully changing the characters;
- replacing or meaningfully changing the maps;
- replacing or meaningfully changing the story/content;
- meaningfully changing another game-content or presentation category; or
- making meaningful gameplay or system changes.

A mere title change, file rename, branding change, packaging change, launcher
change, or other superficial relabeling of an otherwise unchanged Kadoka Quest
copy does not create a Created Game.
